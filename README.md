# 学术简历（Academic CV）静态站点

一个零依赖的纯静态单页学术简历 / CV 网站，适用于国内保研、考研复试、境外博士/硕士申请等场景。移动端优先、响应式、支持中英双语切换、可键盘导航，并内置打印样式（可直接导出 PDF）。

## 文件结构

```
.
├── index.html                  # 页面骨架（语义化标签 + SVG 图标精灵）—— 一般无需修改
├── assets/
│   ├── css/
│   │   └── style.css           # 全部样式：经典学术风格 + 响应式 + 打印样式 + 深浅色主题
│   ├── js/
│   │   ├── resume-data.js      # ★ 所有个人信息集中在此文件（中英双语）
│   │   └── main.js             # 渲染与交互逻辑（语言切换、打印导出等）—— 一般无需修改
│   └── files/                  # 放置 PDF 简历、头像等静态资源
└── README.md
```

## 快速开始

**方式一：直接双击 `index.html`**（无需服务器，可离线打开）

**方式二：本地预览**

```bash
cd 站点目录
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 中英双语使用说明

本站点采用 **数据文件内双语结构**：

- `assets/js/resume-data.js` 中：
  - `profile` 放姓名、联系方式等中英共用信息；
  - `i18n.zh` 放中文版全部文案；
  - `i18n.en` 放英文版全部文案。

**切换方式**：页面顶部导航右侧有「中 / EN」按钮，点击即可在两种语言间切换，选择会自动保存在浏览器中。

**导出英文版 PDF**：先点击顶部「EN」，再按 Ctrl/Cmd + P → 另存为 PDF。

> ⚠️ 注意：中文版与英文版的 **模块结构需要保持一致**。在 zh 里新增了一条论文，也要在 en 里对应新增；否则切到英文时该条会消失。

## 替换为你的信息

只需编辑 `assets/js/resume-data.js`，文件内每一处需要改动的地方都标注了 `【替换】` 或 `【待补充】` 中文注释。改完刷新页面即可。

常见改动位置：

| 想改什么 | 改哪里 |
| --- | --- |
| 姓名、英文名、联系方式、头像 | `profile` 区块 |
| 申请意向 / 身份定位 / 一句话介绍 | `i18n.zh.hero` 与 `i18n.en.hero` |
| 学术概览数字（论文/专利/软著/奖项） | 由系统按你填写的条目**自动统计**，无需手动改 |
| 教育背景（含已获录取但未入学、本科毕业论文） | `i18n.*.education` |
| 研究兴趣 | `i18n.*.research` |
| 论文（Fire Safety Journal 等） | `i18n.*.publications.papers` |
| 专利与软件著作权 | `i18n.*.publications.patents` |
| 科研经历 | `i18n.*.experience` |
| 荣誉奖项 | `i18n.*.awards` |
| 研究计划 / 科普 / 技能 / 自述 / 推荐人 | `i18n.*.proposal` / `outreach` / `skills` / `statement` / `referees` |
| 模块显示顺序 | 文件末尾的 `nav` 数组 |

> 已获录取但未入学的项目填写方式：把 `status` 设为 `'admitted'`，填写 `note` 说明情况，时间写入学年份；页面会自动显示「已获录取」金色标记。

### 编辑注意事项

1. 文本用英文单引号 `'` 包裹；文本里出现单引号要写成 `\'`
2. 数组最后一项后面**不要**加逗号
3. 时间统一写成 `'YYYY.MM'`（如 `'2025.08'`），进行中写 `'至今'`
4. 删除整段条目时，注意同步删掉多余的逗号

## 需要补充的必填占位项

简历中已根据你提供的信息填入了大部分内容，但以下几项在 Word 中没有找到，需要你搜索 `【待补充】` 后补充：

- Fire Safety Journal 论文：**英文标题、作者完整列表、卷期页、DOI**
- 第12届全国大赛一等奖：**获奖作品名称**
- 第12届全国大赛一等奖：**获奖作品名称、团队人数、指导教师**（作品名《多模态 AI 交互探测机器人系统》已填入）
- 高危作业人员资质与身份双验证系统：**实际作者位次、登记号**
- 职业卫生物理危害分级管控软件、在岗人员动态监测服务软件：**登记号、授权时间**
- 建筑施工场地生态环境遥感监测与评价系统、区域碳排放估算与环境安全评估系统：**登记号、授权时间**
- 实用新型专利号
- 英语成绩：**PTE 四项小分与考试日期**（澳洲博士通常要求 IELTS 6.5 且单项不低于 6.0；PTE 56 总分对应 IELTS 6.5，但单项仍需核对）
- 是否掌握 **Python / MATLAB** 等编程/建模工具
- 建议补充：**Google Scholar / ORCID / GitHub 代码仓库** 链接（已在 `profile.contacts` 中注释掉）
- 本科毕业论文 **指导教师姓名与职称**

> 莫纳什硕士录取、直申澳洲博士、可持续能源研究方向等叙事已写入，请在 `【建议核对】` 处改成你自己的说法。

## PDF 简历下载

两种方式，可同时启用：

- **直接下载 PDF**：把 CV PDF 放进 `assets/files/`，然后在 `resume-data.js` 的两套 `resume.pdfUrl` 中填写路径，并在 `pdfFileName` 中指定文件名：
  ```js
  resume: { pdfUrl: 'assets/files/徐其胜-学术CV.pdf', pdfFileName: '徐其胜-学术CV.pdf' }
  ```
  未填写时，下载按钮会自动隐藏，只保留「打印 / 另存为 PDF」按钮。

- **在线导出 PDF**：点击「打印 / 另存为 PDF」，在打印对话框中选择目标为「另存为 PDF」。
  已内置打印样式：自动隐藏导航、按钮、语言切换，强制浅色，避免内容被分页截断。

## 关闭不需要的模块

在 `resume-data.js` 中把对应模块的 `enabled` 设为 `false`，该模块**及其导航项**会自动隐藏：

```js
outreach: { enabled: false, ... }
```

## 部署

纯静态文件，任何静态托管均可：

- **GitHub Pages**：仓库根目录推送后，在 Settings → Pages 选择分支即可
- **Vercel / Netlify**：拖拽整个文件夹上传，无需配置构建命令
- **对象存储 / Nginx**：直接上传目录内容

## 可访问性与技术说明

- **语义化标签**：`header` / `nav` / `main` / `section` / `article` / `footer`，配合 `aria-labelledby` 建立标题关联
- **键盘导航**：提供「跳转到主要内容」跳转链接；所有交互元素可见焦点样式；移动端菜单支持 <kbd>Esc</kbd> 关闭并归还焦点；触摸目标不小于 44px
- **对比度**：正文与背景对比度均达到 WCAG AA（浅色主题正文约 15:1，次要文字 ≥ 5.4:1）
- **减少动态效果**：系统开启「减少动态效果」时，自动关闭平滑滚动与入场动画
- **技能进度条**：使用 `role="meter"` 标注等级
- **结构化数据**：自动生成 JSON-LD（Schema.org Person），便于搜索与招生系统抓取
- **零依赖**：不引用任何第三方库、字体或图标 CDN，可完全离线运行
- **深色模式**：默认跟随系统，可手动切换，选择保存在 `localStorage`
- **中英双语**：顶部一键切换，切换过程不会丢失区块结构

## 浏览器兼容

支持所有现代浏览器（Chrome / Edge / Safari / Firefox 最近两个大版本）。使用了 CSS 自定义属性、`:focus-visible`、`IntersectionObserver` 等特性，不支持 IE。
